# 上海 12 万平方米宾馆分布式冷热电联供系统分析

本仓库提供上海市一座建筑面积为 120000 m2 的中高端宾馆分布式冷热电联供系统的设计阶段情景分析页面、图表和计算数据。

## 在线页面

将仓库上传到 GitHub 后，可在仓库的 `Settings` -> `Pages` 中，将发布来源设为 `Deploy from a branch`，分支选择 `main`，目录选择 `/(root)`。保存后，GitHub 会生成网站地址。网站入口为 `index.html`。

## 内容说明

- `index.html`：可直接发布到 GitHub Pages 的分析网页。
- `assumptions.csv`：设计边界和关键参数假设。
- `hourly-loads.csv`：全年逐时负荷数据。
- `monthly-loads.csv`：逐月负荷汇总数据。
- `scenario-results.csv`：常规分供、冷热电联供和多能互补方案的年度结果。
- `sensitivity-results.csv`：电价和气价敏感性计算结果。
- `*.svg`：网页使用的矢量图表。
- `*.png`：与矢量图表对应的位图备份。

## 使用边界

网页中的负荷、设备、能源价格与投资参数为课程设计阶段的区域平均假设。它们用于说明方案比较方法，不代表具体项目的实测数据或工程报价。实际项目应以建筑图纸、分项计量数据、设备选型资料和商务合同为准。

## 本地查看

双击 `index.html` 即可在浏览器中查看网页。该页面不依赖本地服务器或外部程序。
